# Skinova V1.4.5 — Correctif images strictes

- Correspondance basée sur le nom complet exact `Arme | Skin`.
- Suppression du fallback qui choisissait une autre finition de la même arme.
- Alias uniquement pour la typographie des modèles (`MAC-10`, `UMP-45`, `M4A1-S`, etc.).
- Les anciens liens automatiques incorrects sont migrés au démarrage.
- Si un nom n'existe pas dans le catalogue, Skinova utilise l'image générique du bon type d'arme.
- Les images personnalisées importées dans Skinova Control sont conservées.
