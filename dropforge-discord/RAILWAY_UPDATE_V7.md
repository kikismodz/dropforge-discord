# Mettre la V7 sur Railway

1. Fais une copie de ton dépôt GitHub actuel par sécurité.
2. Remplace les fichiers de ton dépôt par le contenu du projet V7.
3. Ne change pas les variables Railway déjà configurées.
4. Vérifie dans Railway :
   - Root Directory : le dossier contenant `package.json`
   - Build Command : `npm run build`
   - Start Command : `npm start`
5. Fais le commit GitHub.
6. Attends que Railway affiche `Active`.
7. Recharge l'Activity Discord avec `Ctrl + Shift + R`.
8. Vérifie que le bandeau affiche `DISCORD EDITION · V7`.

Le dossier `client/public/assets` est obligatoire : ne le supprime pas.
